# Frontend Mentor - Mortgage Repayment Calculator

A responsive mortgage repayment calculator built with HTML, Tailwind CSS, and vanilla JavaScript.

## Features

- Calculate monthly and total repayments for **Repayment** and **Interest Only** mortgages
- Custom form validation with red error states for incomplete or invalid fields
- Full keyboard navigation and accessible form labels
- Responsive layout across mobile and desktop screens with a **Clear All** reset button

## Built With

- Semantic HTML5
- Tailwind CSS
- Vanilla JavaScript

## Challenge

Solution to the [Mortgage Repayment Calculator challenge](https://www.frontendmentor.io/challenges/mortgage-repayment-calculator-Galx1LXK73) on Frontend Mentor.
